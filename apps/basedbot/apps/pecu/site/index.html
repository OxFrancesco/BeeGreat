Work with Aerodrome on Base from your code or terminal. evmSDK

A toolkit for Ethereum, Base, and other EVM chains. Use the SDK, CLI, terminal interface, or MCP server to inspect contracts, read balances, prepare transfers, and work with swaps and bridges. Shared command schemas make it usable by both developers and agents, while stored transaction plans let you review an action and check its result afterward.

Aero Stocks Web app

Browse tokenized stocks on Base and manage them in your browser. Link your existing BasedBot X wallet to see holdings, preview buys and sells, and set allocations for a stock basket. The app uses the same agent as BasedBot, so you can ask for help in plain language and review transaction proposals before confirming them.
