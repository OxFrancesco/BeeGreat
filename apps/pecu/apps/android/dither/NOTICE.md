# Dither Kit Kotlin

Native Android / Jetpack Compose port of Dither Kit 0.1.0 by ripgrim,
https://github.com/Boring-Software-Inc/dither-kit,
commit `1e7faee9aa252e499651e6736ed65f7a07d9a6bd`.
Retrieved with codeview on 2026-09-27. The upstream package declares MIT in
package.json. It has no separate LICENSE file or copyright notice. The original
source notices and author attribution are retained here and in the source manifest.

The palette, ordered Bayer texture formulas, geometry, deterministic avatar
algorithm, bloom settings, and entrance recipes are translated from upstream.
The Kotlin implementation, Compose state and controls, touch/keyboard/accessibility
support, and Android bitmap rendering are new. This is an independent port.

Upstream credits Evil Charts by legions-developer for the original aesthetic:
https://github.com/legions-developer/evilcharts.
