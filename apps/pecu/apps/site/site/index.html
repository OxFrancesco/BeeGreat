Pecu on X

Send a message to @BeeGreatAI, or sign in with the same X account at pecu.app/agent. The first message on X creates your Base smart wallet through Crossmint. Ask for balances, quotes, swaps, transfers, Aave positions, Nansen analytics or Polymarket odds in plain words or with short commands like /swap and /send. Reads answer at once. Anything that moves money comes back as a preview with a six-character code, and only you, from the same conversation, can confirm it. Enabling YOLO skips confirmation for new transaction requests.

evmSDK

Reads and unsigned plans for any EVM chain. Token balances, allowances, contract reads and decoding, transfers, approvals and arbitrary calls, from the SDK, the evm CLI, a TUI or an MCP server. Pecu runs it inside a Cloudflare Sandbox that cannot sign.
