evmSDK

Reads and unsigned plans for any EVM chain. Token balances, allowances, contract reads and decoding, transfers, approvals and arbitrary calls, from the SDK, the evm CLI, a TUI or an MCP server. Pecu runs it inside a Cloudflare Sandbox that cannot sign.

Questions about Pecu

What can I do with Pecu?

Ask for Base wallet balances, swap quotes, transfers, Aave positions, Nansen analytics and public Polymarket data. Use Pecu in your browser or message @BeeGreatAI on X. Read the Pecu guide.

Does Pecu move money without confirmation?

By default, Pecu prepares a transaction preview that you confirm in the same conversation. YOLO mode skips confirmation for new supported requests. Scheduled transactions need a separate approved allowance. Read the confirmation rules.

How do I fund my Pecu wallet?

Send /wallet to see your Base wallet address, then /deposit for funding options. Check the network and recipient before sending funds. Read the funding guide.

Is Pecu an official Aerodrome product?
