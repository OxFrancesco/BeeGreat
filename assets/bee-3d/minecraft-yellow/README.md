# Bee voxel animations

Saturated yellow Minecraft-style Bee based on the app's canonical pixel mascot. Square eyes, pixel smile, stepped wings and antennae, tiny edge chamfers, and subtle pixel shading.

| Clip | Motion |
| --- | --- |
| fly | Takes off, banks left and right, flutters, and settles |
| happy | Two cheerful hops with smiling pixel eyes |
| sad | Low hover, drooping antennae, and a pixel frown |
| thinking | Head tilts, glances left and right, and focuses |
| fail | Quick recoil and shake, droop, then recovery |
| succeed | Anticipation, rising celebratory spin, and a second hop |
| idle | Gentle hover and blink |

All clips last four seconds at 24 fps. The cube keeps its proportions.

## Files

- bee-animated.blend: editable animation source, opens with fly enabled.
- bee-animated.glb: model with all seven named animation clips. Studio excluded.
- Six individual MP4 previews and bee-animation-reel.mp4, a 24-second reel.
- Portrait, transparent, front, and rear PNG renders.

In Blender's NLA editor, enable one named track at a time across the character's animated objects. The project opens with fly enabled. In a glTF player, select one animation by name. Stop the previous clip when changing expressions. Play fail and succeed once, then return to idle or fly. The other states can repeat.

To regenerate, run tools/bee-3d/build_minecraft_bee.py in Blender, then tools/bee-3d/animate_minecraft_bee.py. The scripts import the existing tools/bee-3d/build_bee.py. Palette and material settings live in tools/bee-3d/bee_appearance.py.

## Verification

Checked all 97 authored frames per clip for body movement, wing movement, and exclusive facial expressions. Exported GLB contains exactly idle, fly, happy, sad, thinking, fail, and succeed. Reimported the GLB into Blender. Each preview has 96 frames at 640 by 640, four seconds at 24 fps.

Mobile and web use the matching app renders generated by tools/bee-3d/render_app_assets.py. The docs homepage and health variants use the same model. Reduced motion uses PNG stills. See docs/25-bee-mascot.md for client behavior and channel coverage. Production and native releases are separate from this source integration.
