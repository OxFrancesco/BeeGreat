# Bee 3D mascot

Bee rebuilt in Blender with a rounded honey body, cocoa stripes, glossy eyes, peach cheeks, curved antennae, little mittens, and four sculpted wings with raised veins.

## Files

- bee-cute.blend: editable source, named parts, editable wing and face curves, materials, camera, studio lights.
- bee-cute.glb: character only, with a gentle hover loop.
- Portrait, front, back, and transparent PNG renders at 1200 × 1200.
- tools/bee-3d/build_cute_bee.py: reproducible Blender build script.

## Verification

Opened the source in Blender 5.2. Inspected front, portrait, and rear renders. Reimported the exported GLB into a clean Blender scene: 81 meshes, 12 materials, one animation, 338736 triangles.

This is the detailed source asset. Runtime optimization and in-app integration are not part of this delivery. Mobile, web, CLI, iMessage, voice, providers, contracts, and backend deployments have no behavior changes. The existing pixel and voxel assets remain available.
