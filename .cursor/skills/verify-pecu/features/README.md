# Pecu feature map

| Feature | Coverage |
| --- | --- |
| [Commands and routing](commands.md) | Slash commands, natural requests, providers, catalog expansion |
| [Transactions](transactions.md) | Previews, confirmations, sends, approvals, swaps, cancellation, expiry |
| [DeFi, stocks and Safes](integrations.md) | Complete lifecycles and prerequisites |
| [Reliability](reliability.md) | History, reconnect, retries, cold starts, memory and latency |

Pecu web and X Chat share backend behavior. Web has rich cards and streaming; X has plain text. BeeGreat mobile, Android, CLI and iMessage are separate clients and do not consume these Pecu endpoints. Sugar and EVM CLI/SDK changes additionally require their own verification skills and standalone releases.
