BeeGreat personal CRM

September 14, 2026. Branch t3code/add-crm-chat-ui.

My Mind now has a CRM tab on web and mobile. Contacts store notes, relationship context, email, phone, follow-up dates, and last-contact dates. Search, archive, and restore use the same records as chat.

The CRM chat card opens the contact editor and reads live Convex data. Bee can find, save, archive, and restore contacts. CLI and iMessage render contact details as text. Follow-up dates do not schedule notifications.

Validation

  • Type checks passed for web, mobile, agent, and backend.
  • Web and agent production builds passed.
  • CRM and account-deletion tests passed. Text-channel contract tests passed.
  • Browser preview verified creation, search, chat-card editing, archive, and restore with synthetic data.

Release state

The Convex backend is deployed to BeeGreat's development deployment. Production web, mobile, and agent releases were not performed. Authenticated full-app chat and physical-device validation remain unverified.

Cap exposed no capturable windows, so no recording was produced. The browser preview is a component test, not a live-account demonstration.
