Measured and exercised

A live Base read loaded 2,671 listed tokens in 3,645 ms. Reusing that catalog took 1 ms with no additional RPC read. These numbers measure the scan cost, not an end-to-end before/after speedup.

A live CLI quote of 0.001 ETH to USDC succeeded in 11,842 ms. No transaction was broadcast. Nine new regression tests reproduce the failures and verify the fixes.

Available locally

The installed aero command points to this package. The updated TUI was verified from the home directory in Ghostty. Existing checkout edits were preserved; the combined worktree was not committed or pushed.

These changes affect Aero's CLI and TUI. Bee's other clients, model providers, transaction contracts, and backend deployments are unchanged.

Apple Terminal failed even a standalone Bun console command. That environment problem remains; Ghostty and the test terminal ran Aero successfully.
