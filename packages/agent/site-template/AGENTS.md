# Bee Site workspace

This is a locked static Astro workspace. Keep all pages static and accessible.

- Pages live in `src/pages` and reusable pieces may live in `src/components` or
  `src/layouts`.
- Shared CSS lives in `src/styles`; public text and image assets live in `public`.
- Do not add dependencies, client scripts, server routes, secrets, analytics,
  transmitting forms, authentication, or payment code.
- `package.json`, `astro.config.mjs`, and `tsconfig.json` are read-only platform files.
